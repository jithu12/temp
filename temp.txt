## What Needs To Be Done Now

The lead has shared the official `platform_health` Python library 
docs. We need to MIGRATE from the current custom Elasticsearch-based 
implementation to use this library.

### Library Overview

Install: pip install platform_health

The library has these main components:

1. CHECKERS — extend platform_health.HZCheckBase to create custom
   checkers for each dependency. Built-in checkers available:
   - HTTPChecker
   - RedisHealthChecker
   - UpstreamServiceChecker

2. HEALTH BASE — main entrypoint:
   from platform_health import Health
   hc = Health(
       datastore_details={
           "redis_host": "<redis sentinel host>",
           "redis_port": "<redis sentinel port>",
           "redis_password": "",
           "sentinel_mode": True,
           "sentinel_master_name": ""
       }
   )

3. RUNTIME — use Celery runtime ONLY (mandatory for CCP):
   from platform_health import Health
   health = Health(hc)
   app = Celery()
   health.register_task_to_celery(app)

   IMPORTANT: Do NOT use HealthExecutor — it cannot be used in CCP.
   For CCP, declare two components in ccp_config.yaml:
   MODULE:
     async: "my_app.celery:app"
     schedule: "my_app.celery:app"

4. REGISTER CHECKS:
   health.register_checks([...list of checker instances...])

5. MODULES — group checkers into modules using module_name parameter
   in each checker. Module names MUST follow format:
   <app-name>:<module-name> e.g. "dataviz:application"

6. DATASTORE — library handles Redis caching automatically.
   Use Redis with Sentinel mode.
