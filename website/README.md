# SG Accessibility Hub — Demo

This is a clickable front-end prototype for the proposed Accessibility Hub.

## Run
Open `index.html` in a browser.

## Demo pages
- Home
- Interpreter Request Center
- My Accessibility Preferences / Teams Status
- Accommodation Request
- Accessibility Issue Reporter
- Accessibility Toolkit
- Emergency Accessibility
- Manager View
- Analytics

## Notes
- All information is fictional demo data.
- Forms do not connect to real SG systems.
- Teams status buttons are demo placeholders until SG IT/API permissions are confirmed.
- Replace demo content with approved internal SG processes and links before any real use.
